БУКОВЕЛЬ РП — сайт правил

Файли:
- index.html — сторінка сайту
- css/style.css — оформлення та анімації
- js/app.js — перемикання екранів, мови, пошук і категорії
- js/translations.js — українська та російська мови
- js/rules.js — дані правил сервера
- js/criminal.js — дані кримінального кодексу

ВАЖЛИВО:
Тексти правил поки не додані. Їх потрібно перевірити та перенести з джерела,
оскільки сайт-джерело показує правила через JavaScript і їх не вдалося прочитати
звичайним переглядом сторінки. Не публікуйте цей шаблон як остаточний звід правил.

Публікація через GitHub Pages:
1. Створіть новий репозиторій на GitHub.
2. Завантажте ВСІ файли та папки зі ZIP, зберігши структуру.
3. У Settings → Pages оберіть Deploy from a branch.
4. Оберіть гілку main та папку /(root), натисніть Save.
