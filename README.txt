У ZIP є готова структура:
- index.html
- css/style.css
- js/app.js
- js/translations.js

ЯК ОНОВИТИ САЙТ НА GITHUB:
1. Розпакуйте ZIP.
2. Відкрийте репозиторій GitHub.
3. Замініть файли index.html, css/style.css та всі файли в js на однойменні з архіву.
4. Не залишайте старий app.js або старі файли даних — вони можуть конфліктувати.
5. Збережіть зміни (Commit changes) і зачекайте оновлення GitHub Pages/хостингу.

ВАЖЛИВО ПРО МОВУ:
Перемикач UA/RU працює, запам'ятовує вибір у браузері та перекладає інтерфейс. Тексти статей збережені мовою оригіналу, як вони були надані у вихідних матеріалах; автоматично не переписувалися, щоб не змінити юридичний зміст. Для повністю російських текстів потрібен окремий перевірений переклад статей.

ВАЖЛИВО ПРО ЗМІСТ:
У наданому кримінальному кодексі розділ 18 містить 6 узагальнених пунктів і згадує 44 статті, але повного тексту всіх 44 статей у джерелі немає. Відсутні статті не вигадувалися.
У вихідному законодавстві збережені наявні номери та формулювання, включно з нумерацією транспортного розділу 5.x у розділі 15.
