ЛЬВІВ РП — українська версія сайту законодавства

У ZIP є готова структура:
- index.html
- css/style.css
- js/app.js
- js/legislation.js
- js/criminal.js

ЩО ЗРОБЛЕНО
- залишено тільки українську мову;
- прибрано перемикач RU;
- залишено два розділи: «Законодавство сервера RP» та «Кримінальний кодекс»;
- картки правил спочатку закриті й відкриваються натисканням;
- окремий пошук у кожному розділі;
- 3 картки в ряд на комп'ютері, 2 на планшеті, 1 на телефоні;
- зимовий темний дизайн, сніг та адаптивна верстка.

ВСТАНОВЛЕННЯ
1. Розпакуй ZIP.
2. Завантаж на GitHub файли та папки зі збереженням структури.
3. Замінюй однойменні файли, а не створюй дублікати.
4. Перевір, що папки css і js лежать поруч з index.html у корені репозиторію.
5. Натисни Commit changes.

ДАНІ
Тексти в js/rules.js взяті зі старого архіву bukovel-rp-dark-winter-complete.zip без змін. Кримінальний кодекс — із наданих матеріалів.
